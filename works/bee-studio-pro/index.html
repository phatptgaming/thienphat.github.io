TỔNG QUAN

Bee Studio Pro là ứng dụng desktop (Electron + React + TypeScript) phục vụ sản xuất video hoạt hình 2D với giao diện tiếng Việt. Dự án được xây dựng từ đầu: milestone đầu có thư viện nhân vật, dựng scene theo timeline và render MP4 thật; milestone tiếp theo bổ sung lưu trữ SQLite, nhập audio có waveform, undo/redo và quản lý tiến trình render.

THÁCH THỨC

Người làm nội dung hoạt hình cần một quy trình dựng–xem trước–xuất bản khép kín trong một ứng dụng duy nhất, thay vì chuyển đổi qua lại giữa nhiều công cụ rời rạc.

Ý TƯỞNG SÁNG TẠO

Lấy timeline làm trung tâm: nhân vật là tài sản tái sử dụng, scene là đơn vị kể chuyện, và bản render là đầu ra có thể kiểm chứng bằng thông số file thật (codec, độ phân giải, thời lượng).

QUY TRÌNH
  1. 01Nghiên cứu quy trình làm phim hoạt hình 2D
  2. 02Thiết kế thư viện nhân vật & cấu trúc scene
  3. 03Dựng timeline và bản render MP4 kiểm chứng đầu tiên
  4. 04Bổ sung SQLite, audio waveform, undo/redo
PHÁT TRIỂN

Electron + React + TypeScript; render bằng FFmpeg. Bản test đã kiểm chứng: MP4 H.264 1280×720, 24fps + AAC, đúng 6.0 giây; 26/26 test đạt ở milestone 2. Bản Windows EXE chưa được build/kiểm chứng trên máy Windows thật.

TRƯNG BÀY
KẾT QUẢ & TRẠNG THÁI

Trạng thái trung thực: đang phát triển, chưa phát hành. Giới hạn đã biết: giao diện còn ghi song song SQLite/JSON, file audio tham chiếu theo đường dẫn, GUI Electron chưa test E2E.
